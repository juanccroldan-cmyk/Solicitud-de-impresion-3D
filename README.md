# Solicitud de impresión 3D · Taller Si3

Formulario web para que las plantas Si-Plásticos, Si-Ensambles e Iberotech soliciten impresiones 3D al taller.

- Publicado con GitHub Pages desde la rama `main`.
- Las solicitudes se envían por correo al taller mediante FormSubmit.
- Para cambiar el formulario, edite `index.html` y haga commit en `main`. Los cambios se publican en 1 a 3 minutos.
